# Учебный мод для Factorio

Небольшой экспериментальный мод для Factorio 2.1 на русском языке. Добавляет супер-уголь и супер-печь, а также несколько игровых команд и примеров работы с событиями.

> Мод создан в учебных целях. Некоторые механики — эксперименты и могут меняться.

## Возможности

- **Супер-уголь** — производится из 5 угля и 2 древесины, даёт 50 МДж энергии.
- **Супер-печь** — создаётся из каменной печи и 10 стали; плавит в 50 раз быстрее обычной печи. Оба рецепта открываются технологией «Обработка стали».
- **Бесплатное топливо** — первые три построенные супер-печи получают по 5 единиц супер-угля.
- **Сканер ресурсов** — ищет ближайшие залежи в области 20 × 20 клеток вокруг игроков.
- **Экспериментальные команды** — позволяют создавать управляемых юнитов и отправлять их к найденному ресурсу.

## Установка

1. Скачайте ZIP-архив репозитория через **Code → Download ZIP** и распакуйте его.
2. Переименуйте распакованную папку в `learning_<версия из info.json>` (например, `learning_0.0.508`) и поместите её в папку модов Factorio:
   - **Windows:** `%APPDATA%\Factorio\mods\`
   - **Linux:** `~/.factorio/mods/`
   - **macOS:** `~/Library/Application Support/factorio/mods/`
3. Включите мод в меню **Моды** и перезапустите игру.

На Windows для установки можно запустить `update-mod.ps1` из папки проекта. Скрипт копирует мод в пользовательскую папку Factorio; запуск может потребовать разрешения PowerShell на выполнение сценариев.

## Игровые команды

Введите команду в игровом чате или консоли Factorio:

| Команда | Назначение |
| --- | --- |
| `/reset-refills <число>` | Установить число оставшихся бесплатных заправок. |
| `/toggle-scanner` | Включить или выключить поиск ресурсов. |
| `/spawn-worker` | Создать экспериментального юнита рядом с игроком. |
| `/send-worker` | Отправить свободного юнита к последнему найденному ресурсу. |
| `/remove-workers` | Удалить созданных этой командой юнитов. |

Поиск выполняется раз в секунду и останавливается после обнаружения ресурса. Сканер хранит одну последнюю найденную позицию; команда отправки использует именно её. Юниты пока только перемещаются к цели — добыча ресурсов не реализована.

## Разработка

Исходный код организован по этапам загрузки Factorio:

- `data.lua` и `prototypes/` — игровые предметы, рецепты и сущности;
- `control.lua` и `scripts/` — события, команды и логика во время игры;
- `locale/` — переводы интерфейсных строк.

На Windows скрипт `update-mod.ps1` устанавливает текущую версию, не меняя номер версии. Скрипт `deploy-mod-on-save.ps1` предназначен для локальной разработки: он увеличивает patch-номер в `info.json`, архивирует предыдущую версию и устанавливает новую. Не запускайте его для обычной проверки — каждое выполнение меняет версию.

Рекомендуемые расширения VS Code перечислены в `.vscode/extensions.json`. Для дополнения кода настройте Factorio Mod Debug Tool под собственную установку игры; локальные пути намеренно не включены в репозиторий.
